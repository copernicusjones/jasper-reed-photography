What to Include

For spreadsheet cleanup

  • The file (.xlsx, .csv, or .ods, under 50MB)
  • Rows you need covered
  • Where it's being imported into
  • Any column that must not change

For stock-photo keywording

  • The images, or a link to the gallery
  • Photo count
  • The agency and its keyword standard, if you have one
  • Output format you need

For a website QA report

  • The site URL
  • The flows that matter most (signup, checkout, contact)
  • Pages to cover
  • Mobile testing — needed or not

For an automation build

  • The current manual process, step by step
  • Which tools are involved (n8n, Make, Zapier, Sheets, Airtable, a CRM)
  • The one outcome you want automated first
  • What happens today when it goes wrong

What Happens Next

  3. You approve it. A payment link is issued.
  4. The work is delivered with an evidence report. One revision round is included.
